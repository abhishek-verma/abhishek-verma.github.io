Microsoft killed Claude Code for 100,000 engineers

When a vendor decision can yank a coding agent from tens of thousands of engineers overnight, the real story is not the model - it is dependency, workflow lock-in, and how fragile “AI productivity” becomes when the tool is rented. The piece walks through what broke, who felt it, and why teams that treat agents as infrastructure need exit ramps, local control, and evaluation that survives a provider change.

Written for engineers and leads who ship with agents daily and need to think about continuity the same way they think about CI or cloud regions.

2025

Architecting LLM systems for scale

Handling noisy streams like logs or security events means trading cost against accuracy. Large models reason well but burn money at millions of events; small models are cheap but miss hard cases. The answer is selective routing: an SLM handles the default path, uncertainty estimation decides when to escalate, and an LLM only sees curated, retrieval-augmented context.

Drawing on AdaptiveLog: Bayesian confidence gates, error-case memory in prompts, ~73% fewer LLM calls, and better accuracy on hard samples. A design pattern for hybrid AI - place each model where it is strongest instead of one monolithic LLM.
